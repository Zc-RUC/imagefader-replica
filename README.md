# ImageFader Replica

> **复刻声明：本项目是对 [ImageFader](https://imagefader.com/) 的非官方复刻，不是原站官方项目。**
>
> 原站名称、品牌及原始实现的相关权利归原权利人所有。本仓库用于学习前端界面设计、Canvas 图片处理与浏览器本地交互。

## 项目简介

保留 ImageFader 的单图透明编辑能力，并按照 Kimi 创意设计规范重新设计首页与编辑器界面。新版采用冷白与柔和紫色、无衬线排版、统一的 SVG 图标，以及桌面三栏 / 移动单栏工作台。

图片读取、效果预览和导出均在浏览器本地完成，不需要账号，不上传原图，也没有统计上报。

## 功能

- 整体透明：均匀调整整张图片的不透明度
- 渐变透明：线性、径向和扇形渐变，支持方向、范围、中心点和反转
- 边缘羽化：矩形、椭圆、单边或四周羽化
- 局部透明：矩形、椭圆与画笔选区，支持增加、还原、反选和选区羽化
- 预览辅助：棋盘格、白色、黑色或自定义背景，辅助线与原图对比
- 透明导出：PNG / WebP，保留原始像素尺寸；WebP 支持质量调节
- 多种输入：点击选择、拖拽和粘贴 PNG / JPG / WebP 图片
- 响应式界面：桌面与移动端均可使用，移动端提供固定导出栏

## 本地运行

本项目是无构建步骤的原生 Web 应用，不需要安装 npm 依赖。

```bash
cd imagefader-replica
npm run dev
```

打开 <http://127.0.0.1:5173>。

也可以直接使用 Python 启动静态服务器：

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

要求：现代浏览器；`npm run dev` 使用本机 Python 3 提供静态服务。

## 使用方式

1. 上传或粘贴一张图片。
2. 选择整体、渐变、羽化或局部模式。
3. 使用预设、滑杆或画布控制点调整效果。
4. 选择 PNG 或 WebP，下载保留真实 Alpha 通道的图片。

## 代码检查

```bash
npm run check
```

该命令检查所有 JavaScript 文件的语法。项目还通过了桌面与移动端的上传、模式切换、局部画笔、透明像素和实际文件下载验证。

## 目录结构

```text
.
├── index.html              # 首页与编辑器挂载点
├── css/
│   ├── style.css           # 首页、组件与响应式设计系统
│   └── editor.css          # 编辑器工作台与移动布局
├── js/
│   ├── main.js             # 编辑器界面、状态与交互
│   ├── image-core.js       # 图片解码、Alpha 处理与导出
│   ├── ui-icons.js         # 内联 SVG 图标
│   ├── editor-startup.js   # 编辑器加载前的上传衔接
│   ├── analytics.js        # 本地空实现，不发送分析数据
│   └── locale.js           # 语言偏好辅助（当前页面未启用自动跳转）
├── images/                 # 品牌图片资源
├── manifest.webmanifest
└── package.json
```
